# Plan

> **Template.** Written between minutes eight and twelve, and frozen at minute
> twelve. Writing to this file triggers an automatic adversarial review before
> any implementation begins.

## Scope

Every entry cites a requirement identifier from `00-brief-analysis.md`.

### Must

The exercise fails without these. Keep this list brutally short: there are
twenty six minutes of building, and a must list that does not fit is not a plan.

### Should

Built only if the must list finishes early.

### Will not

Named explicitly, each with one line on why that is the right call. This list is
quoted in the walkthrough. Scope discipline that is written down reads as
judgement; scope that quietly disappears reads as an omission.
